# Zainab's Tastee Galour — ordering website

Live site: https://zainabs-tastee-galour.vercel.app

- `index.html` — the whole website (menu, cart, checkout, WhatsApp + email ordering).
- Store settings (WhatsApp number, prices, delivery fee, hours, email endpoint) are in the `STORE` and `MENU` blocks near the top of the script in `index.html`.
- Every push to `main` is deployed automatically by Vercel to the live link above.
